# NodeBridge

Obsidian 插件：在关系图谱中点击两个笔记之间的连线，在中间创建一个新节点。

## 功能

- 在 Graph View 中开启「插入节点」模式
- 点击两个笔记节点之间的连线，弹出创建对话框
- 新笔记自动双向链接两端原节点
- 可选「断开原连接」：取消两篇原笔记正文中的互链，形成链式结构
- 支持选择保存位置、新建文件夹
- 自动记住上次使用的保存位置

## 安装

1. 下载 `main.js`、`manifest.json`、`styles.css`
2. 放到笔记库的 `.obsidian/plugins/my-second-plugin/` 目录下
3. 在 Obsidian 设置 → 第三方插件中启用

## 使用

1. 打开关系图谱
2. 点击左下角「插入节点：关」按钮开启模式
3. 鼠标移到连线上会高亮显示
4. 点击连线，在弹出的对话框中输入新节点名称即可创建

## 注意

- 仅支持桌面版 Obsidian
- 需要 Obsidian >= 1.14.5
- 依赖图谱内部 API，Obsidian 大版本更新后可能需要适配
